Мой 1 репозиторий на гитхабе
Учебный репозиторий для настройки линтеров и pre-commit.

ведения репозитория
- Работаем в отдельных ветках (feature/..., fix/...), в main напрямую не пушим.
- Любое изменение идёт через Pull Request.
- Коммиты пишу по шаблону: feat: ..., fix: ..., docs: ....
- Перед коммитом автоматически запускаю линтеры.

Подробности в смотри в этом документе -> CONTRIBUTING.MD
